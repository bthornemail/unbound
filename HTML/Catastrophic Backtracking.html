The pattern

Two patterns that accept the same strings

Both match “one or more a’s, and nothing else” — exactly the same strings. One is a trap.

/^a+$/  — one or more a's /^(a+)+$/ — one or more groups of one or more a's

Feed each a run of a’s ending in one character that can’t match — "aaaa…!". The first says “no” at once. The second must prove no arrangement works first, and that is the fall.

Why

The engine chases every path

The nested form is ambiguous: there are exponentially many ways to split a run of a’s into “groups of a’s.” For four a’s alone:

aaaaaaa · aaa · aa a · aaaaa · a · a… and more

A backtracking engine tries one split, walks to the end, hits the !, fails, backs up, and tries the next — all of them — before it can answer “no.” The count roughly doubles with each character added. That is the climbing curve, and the compass needle swinging right.

The fix

Hold the set; step once per character

Don’t commit to a path and back up. Keep the set of every place the pattern could be at once, and advance the whole set by one character at a time. Each step is one bounded move; when the input ends, check whether any live place accepts.

There is never anything to back up from, because you never chose a single path — you carried them all together. The work is one pass: linear, however ambiguous the pattern. That is the flat line, and it is the idea Ken Thompson published in 1968 — why tools like grep and RE2 cannot be made to blow up.

Same pattern, same input — years collapses to under a millisecond, just by refusing to guess.

The principle

The blowup is the test

This is the shape of every search that explodes: pick one possibility and plan to back up if it fails, and the failures multiply. Carry all the possibilities together and move them in lockstep, and the explosion flattens into a walk.

So the blowup is diagnostic. If a matcher — or any step-by-step process — explodes, it is chasing paths one at a time. If it stays linear, it is holding the whole set and advancing it by one step. You can tell which from the clock alone.

Five runs were measured directly (16→16 ms, 20→44 ms, 24→703 ms, 26→2 951 ms, 28→13 502 ms); the curve is 15 + 7.58e-6 · 2.14ⁿ ms, which passes through them.
